# Security Policy

## Supported versions
Only the latest release (2.x) receives fixes.

## Reporting a vulnerability
Please do not open a public issue for security problems.
Use GitHub's "Report a vulnerability" button on the Security tab of this
repository, and include steps to reproduce.

Note: TranscriptForge's YouTube access layer comes from the upstream project
youtube-transcript-api. Issues in that layer may also need to be reported there.
